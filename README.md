# kanso

![kanso](preview.png?v=7)

极简探针（[Monitor](https://github.com/monitor-probe/monitor)）的第三方主题，源码基于上游默认主题
`monitor-theme-default` v1.1.0 改造。纯静态前端，只读 hub 的公开接口，
国旗与图标资源都自带。

## 安装

首次安装需从 Releases 下载 theme.tar.gz 上传至探针后台，后续可在主题卡片上点击从 GitHub 更新。

## 关于备注

备注有**两处来源**，都在 hub 后台的节点里填：

1. **「公开备注」**（hub ≥ 1.3.2，单行 ≤100 字）——写给访客看的那条，随公开视图下发，匿名访客也拿得到；
2. **「私有备注」**——写给自己的那条，只下发给登录的管理员，
   访客拿不到。

**两边写法一致**：逗号分隔就是多枚，一枚一枚各自成小卡片（半角 `,` 与全角 `，` 都认，两侧空白削掉、
空片段丢掉）；私有那条多一手「按换行也拆」（hub 对它没有单行约束，常有人把几件事分行写）。

**合并后只摊在卡片上**：私有在前（带锁 + 描边，只有登录的自己看得到）、公有在后；访客那边 hub
不下发私有备注，所以同一个位置他们看到的只有公有那几枚。**卡片底注那一行最多摊三枚**
（1.6.0 起备注只显示在卡片上：整页详情不再摊备注，也没有任何开关）。

## 设置

**不提供主题设置**：1.6.0 起本主题不声明任何设置项，后台主题卡片上也没有「主题设置」入口 ——
没有开关可调：

- **备注**：只显示在卡片上（底注那一行最多 3 枚）；整页详情不摊备注。
- **明暗**：跟访客系统的 `prefers-color-scheme` 走；访客点过顶栏那枚太阳/月亮图标就以他的为准
  （只存在他自己的浏览器里；点回与系统当前一致的一档＝重新跟着系统走）。

**站点图标不在主题侧**：hub 1.4.0 起由面板的「设置 → 站点图标」管 —— 选好之后浏览器标签页、
书签、手机主屏幕与顶栏那枚圆形站标一起换，**换主题也保留**；主题自带的那份只在没设图标时兜底。
