# kanso

![kanso](preview.png?v=3)

极简探针（[Monitor](https://github.com/monitor-probe/monitor)）的第三方主题，源码基于上游默认主题
`monitor-theme-default` v1.1.0 改造。纯静态前端，只读 hub 的公开接口，
国旗与图标资源都自带。

只做一件事：把「简约」那一档卡片做到头 —— 一个列表、一张卡片、一页详情。没有第二档形态、
没有地球、没有统计卡；设置只有两项。

## 安装

首次安装需从 Releases 下载 theme.tar.gz 上传至探针后台，后续可在主题卡片上点击从 GitHub 更新。

## 预览

![预览](preview.png?v=3)

**列表页**：搜索框（名称、地区、系统三处都能搜）、离线自动沉底，**一行两张宽卡**（768 以下单列），
每台一张卡片 —— 状态点 + 旗子领着一行名字，下面依次是 `系统 · 运行时间`、四个读数格（CPU / 内存 /
存储 / 负载，各带一条进度）、上传 / 下载两栏（累计总量与实时速率）、总流量（已用 / 额度 + 重置日，
一条全宽带），底注是价格 / 到期与最多三枚备注小卡片。卡面不含延迟走势——那在整页详情里看（点卡片进去）。

**整页详情**：延迟走势图（可切量程、削峰）、资源曲线、读数盒、备注小卡片、明暗跟随。

## 与母本的关系

这一版走「单档」路线：只保留**「简约」一档卡片形态**，其余整块去掉（五档形态与顶栏那枚形态切换菜单、
节点地球与地区列、概览卡片、分组标签、紧凑列表页、备注位置四选一、延迟线路手选）。

留下的两处设置见下。旧版残留的键（`cardStyle` / `listTop` / `pingLines` / `remarkPlacement` /
`globeOn` …）读到一律丢弃，不留在暗处生效。

## 关于备注

备注有**两处来源**，都在 hub 后台的节点里填：

1. **「公开备注」**（hub ≥ 1.3.2，单行 ≤100 字）——写给访客看的那条，随公开视图下发，匿名访客也拿得到；
2. **「私有备注」**——写给自己的那条，只下发给登录的管理员，
   访客拿不到。

**两边写法一致**：逗号分隔就是多枚，一枚一枚各自成小卡片（半角 `,` 与全角 `，` 都认，两侧空白削掉、
空片段丢掉）；私有那条多一手「按换行也拆」（hub 对它没有单行约束，常有人把几件事分行写）。

**合并后两处都摊**：私有在前（带锁 + 描边，只有登录的自己看得到）、公有在后；访客那边 hub
不下发私有备注，所以同一个位置他们看到的只有公有那几枚。**卡片那一侧的底注行最多摊三枚**、
**整页详情那一侧全部摊**（详情页那一侧由主题设置 `detailRemarks` 控制，卡片那一侧不受它影响）。

## 主题设置

后台「主题」页的「主题设置」，改完对访客立即生效（值存在 hub 的站点配置里，访客端不落副本）：

**站点图标不在这一页**：hub 1.4.0 起由面板的「设置 → 站点图标」管 —— 选好之后浏览器标签页、
书签、手机主屏幕与顶栏那枚圆形站标一起换，**换主题也保留**；主题自带的那份只在没设图标时兜底。

| 分组 | 设置项 | 默认 | 说明 |
|---|---|---|---|
| 节点信息 | 详情页显示备注 | 开 | 备注小卡片在整页详情显示／不显示。关掉＝hub 里填了也不摊；卡片侧无论如何都不摊。 |
| 外观 | 主题模式 | 随系统设置 | 整站的明暗，四选一：**随系统设置**（默认，跟访客的 `prefers-color-scheme` 走）／**随北京时间自动切换**／**亮色**／**暗色**。「自动」按**北京时间 19:00–07:00 用暗色、其余用亮色**（中国不实行夏令时，固定 UTC+8），页面开着跨过这两个点也会自己换过来（每分钟问一次钟点）。访客点过顶栏那枚太阳/月亮图标就以他的为准（同样只存在他自己的浏览器里，点回与这里相同的一档＝重新跟着这里走）。 |
